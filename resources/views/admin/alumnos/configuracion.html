🚀 PASO 1 — Instalar paquete

composer require maatwebsite/excel

🚀 PASO 2 — Crear Modelo y Migración

php artisan make:model Alumno -m

Migracion

php artisan migrate

🚀 PASO 3 — Crear Import

php artisan make:import AlumnosImport --model=Alumno

🚀 PASO 4 — Crear Controlador

php artisan make:controller AlumnoController

🚀 PASO 5 — Rutas

Route::get('alumnos/importar', [AlumnoController::class, 'index'])->name('alumnos.importar');

Route::post('alumnos/importar', [AlumnoController::class, 'importar'])->name('alumnos.importar.store');

🚀 PASO 6 — Vista Blade

resources/views/alumnos/importar.blade.php
